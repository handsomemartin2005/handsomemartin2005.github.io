Jun. 2026 - Aug. 2026

Summer Research Intern, University of Virginia

  • Built a state-level influenza early-warning data loop from CDC, Google Trends, weather, hospitalization, wastewater, and holiday signals.

2026

Atlas Repository-Level LLM Integration Study, ESEM Submission

  • Designed and implemented Atlas, a repository-level analysis framework for identifying real LLM component integration across source code, dependencies, configs, READMEs, Dockerfiles, issues, and commits.
  • Built an LLM keyword library and component normalization dictionary to standardize model families, inference frameworks, API providers, deployment backends, and parameters across files and components.
  • Combined multi-source evidence fusion with LLM-assisted semantic reasoning to classify components, functional roles, loading and deployment patterns, API providers, and usage behaviors.
  • Constructed a 200-repository benchmark and applied Atlas to 12,991 active GitHub repositories, identifying 1,036 LLM-integrated projects, 75 plaintext API credential leaks, and 70 license-compliance risks with responsible disclosure.
